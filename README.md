# aws_iac_automation_training

Berlatih untuk Infra as Code dalam VPS AWS

Provisioning Infrastruktur (Terraform):

Membuat VM Server (EC2 Instance) di AWS secara otomatis.

Mengatur jaringan dan Security Group 

Alokasi & attach IP Statis (Elastic IP).

Konfigurasi Server & Deployment (Ansible + Docker Compose):

Install Docker & Docker Compose di dalam VM.

Menjalankan container web server (Nginx).

Menjalankan stack monitoring (Prometheus + Grafana + Node Exporter).

Otomatisasi CI/CD (GitHub Actions):

Setiap kali git push, GitHub Actions otomatis menjalankan Ansible untuk memperbarui deployment di VM EC2 secara otomatis.
